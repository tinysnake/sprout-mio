# Web UI 与 PWA：决策记录

状态：本文记录已确认的交互方向，不代表实现已经完成。业务范围与分期以 [core-scope.md](core-scope.md) 为准；具体页面布局和路由格式留待设计。

## 实现基础与重构范围

- 参考原 [Sprout](https://github.com/tinysnake/sprout) 的生产 Web 代码与设计，依据 Mio 的现有需求进行重构，不能直接照抄旧界面和业务规则。
- 支持桌面端和手机端，采用 single page app（SPA）。当前客户端形态构思到 Web 与 PWA，尚未选定或承诺原生 desktop / mobile App 的容器技术。
- 优先复用或改造符合新需求的基础组件、主题、跨端布局、软键盘视口、聊天滚动及连接处理。旧业务规则须按 Mio 的 Conversation、Task、分身、run 和租约定义逐项检查。
- Projects 页面变化较大；其余页面以省去不适用的信息和调整必要业务行为为主，基本结构无需全面重做。
- UX 细节在实际使用过程中逐步完善，不把多行输入、富文本、草稿同步等此前讨论的建议自动变成新的前置要求。

## 一级导航与功能层级

一级导航确定为：

| 入口 | 定位 | 二级功能方向 |
| --- | --- | --- |
| Projects | 项目列表与具体项目内的协作 | 可有二级功能，具体栏目留待设计 |
| Agents | Agent profiles 的列表与详情 | 当前不增加二级功能导航 |
| Machines | Machines 的列表与详情 | 当前不增加二级功能导航 |
| Management | 管理功能 | 可有二级功能，具体栏目留待设计 |

- 不设置 Feed 页面。
- 当前可能需要二级功能导航的只有 Projects 和 Management；对象详情和编辑界面仍可以有自己的路由，不等同于新增二级功能栏目。
- Conversation、Task 和项目相关的 Info Hub 信息在 Projects 内组织，不作为新的一级入口。
- 桌面与手机沿用相同的一级导航与功能含义，具体布局按设备调整。

## SPA 与 URL 定位

- 每个功能入口、对象详情及需要直接定位的操作界面都应有对应 link。用户能保存、复制并直接打开 URL，快速回到目标位置。
- 打开指定 Project 的 URL 时直接进入该 Project，跳过项目选择；打开该 Project 内指定 DM、Group 或 Public Channel 的 URL 时直接进入对应聊天窗口。
- Task、Agent、Machine 的详情，以及需要直接进入的编辑或操作界面，同样应支持 URL 定位。
- URL 必须携带足够的定位信息，不依赖此前已在页面中选择过 Project 或对象，也不依赖内存中的导航历史。
- 同一 URL 在刷新、重新打开、浏览器前进与后退时恢复对应的目标与上下文；桌面、手机及 PWA 使用一致的 URL 语义。
- 路由由 URL 确定当前目标。桌面可以展示列表与详情并排，手机可以展示全屏详情，目标含义保持一致。
- link 定位页面与操作界面；修改状态的动作仍由用户在对应界面中执行，打开或刷新 URL 本身不重复执行动作。
- 具体 path / query 格式留待技术设计。Project 内的定位和数据读取继续遵守已有 Project 隔离与授权边界。

## Info Hub 在前端的呈现

- Info Hub 是基本信息的聚合与访问功能模块，为各处展示提供数据。其职责不以某个页面为边界，不设置独立的一级 Info Hub 页面。
- 任何页面或组件需要展示相关信息时，都可以按需从 Info Hub 获取；下列位置是展示示例，不是模块服务范围的限制。源对象维护事实与操作，Info Hub 提供聚合与查询，各界面负责呈现并沿用一致的状态和关联含义。
- 展示位置包括 Project 页面、Conversation 侧边栏或手机对应的信息视图、Task 详情、Agent 简单信息与详细信息页面，以及相关 Machine 页面。
- 各处展示当前上下文需要的状态与关联，并支持通过 link 定位关联对象；不要求用户先进入统一汇总页才能查看。
- 分散展示不改变源对象的事实、状态含义或操作权，也不改变 Agent 获取快照、变更提示和主动查询的规则。
- 具体信息范围继续以 [Info Hub 决策](info-hub-decisions.md) 为准。

## PWA 边界

- 定位为可安装、可独立窗口打开的在线协作客户端，并清楚处理断线与恢复。
- 可以缓存界面资源；若展示上次读取的数据，须标明离线或更新时间，不能把旧状态当作当前事实。
- 发消息、修改 Task、停止运行、收回租约等操作展示实际请求结果；不默认在离线时排队并在联网后自动执行。不能确认的结果明确表示未知。
- 关闭页面、切后台或切换设备不作为停止服务端 Agent 或远端长命令的操作；重新进入时同步当前事实。
- 可安装的 PWA 不自动包含系统推送。推送能力、目标平台验证及服务端投递另行评估，不作为本轮已确认的支持承诺。
- 手机访问需要可达的 Sprout 服务地址及登录入口；具体远程连接与部署方案留待技术设计。
